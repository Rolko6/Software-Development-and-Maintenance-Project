## Prompt record naming

Name each prompt record `docs/ai/prompts/YYYY-MM-DD-<person>.md`, where `<person>` is the GitHub username of the person who gave the prompts (for example `2026-09-24-yyy-tom.md`). Keep one file per person per day and start every entry with a `Person:` line. This repeats the rule in AGENTS.md so it is visible even when the import is not loaded; the [AI evidence guide](docs/ai/README.md) has the full procedure.
